How this tool works

Item Type and Department start as keyword guesses (or a real ServiceTitan category, where one exists) — correct them as you review; they drive grouping and sort.

Save commits a row and stamps Last Reviewed — the only "when was this touched" record that exists, since ServiceTitan's export has no modified-date field. It only knows about reviews done here.

Images upload directly in ServiceTitan (per-item media icon, or Bulk edit pricebook items) — not through this file. Attach file resizes/compresses a photo to ServiceTitan's spec (450×450px, under 100KB) automatically; download the zip before switching machines, since photos live only in this browser tab.

Vendor shown faded and italic ("Default Replenishment Vendor") is ServiceTitan's generic fallback, not a real supplier.

Plan Bulk Edit gives you a code list + exact settings to replicate a batch change in ServiceTitan's own Bulk Edit screen.

The Changes List and Vendor Pricing downloads are tracking/reference files, not ServiceTitan-ready imports — bring them back here when you're ready to push a batch live and I'll merge it into a full untouched copy of your original export.

This page now lives alongside Job Review in the same site, and loads its data from files in this repo instead of being baked into the file you download.
